# Triage Labels

For the local markdown tracker, triage state is a `Status:` line near the top of each issue/spec file.

| Role in skills     | Status string      |
| ------------------ | ------------------ |
| `needs-triage`     | `needs-triage`     |
| `needs-info`       | `needs-info`       |
| `ready-for-agent`  | `ready-for-agent`  |
| `ready-for-human`  | `ready-for-human`  |
| `wontfix`          | `wontfix`          |
