Mapa da carga OCE

Folha rápida para explicar ao time. Detalhe na aula 1 e em CONTEXT.md.

Fluxo (uma frase por etapa)

  1. 1 · Bubble / curl Envia CSV do Lote OCE com API key → POST /v1/lotes
  2. 2 · API Go Valida auth + parseia CSV → cria Job de Aplicação queued
  3. 3 · Worker FIFO: um Job por vez → running → batches
  4. 4 · Supabase Progresso em oce_job; Situação OCE em escola via RPC
  5. 5 · Bubble Lê oce_job (não precisa GET na API Go)

Peças do repo

cmd/oce-processamento — sobe HTTP + worker

internal/httpapi — ingestão autenticada

internal/lote — parser do CSV

internal/worker — fila, batch, retry

internal/supabase — adapters PostgREST

docs/sql/* — oce_job + RPC de batch

Regras que o time precisa lembrar

  • Não cria Escola — INEP inexistente é no-op
  • Só 3 colunas OCE em escola
  • CSV temporário (sem Storage); itens do lote ficam na memória do processo
  • Job failed → reenviar CSV (seguro para estado final)
